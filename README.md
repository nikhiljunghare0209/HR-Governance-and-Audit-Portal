# HR-Governance-and-Audit-Portal
 
Frameworks and Libraries: React, Node.js, Express.js, MySQL



• Built a full-stack Employee Management System using React, Node.js, Express, and MySQL for managing
employee records.

• Implemented CRUD operations with raw SQL, including soft delete and restore to prevent permanent data loss.

• Added admin audit logs and email notifications (Nodemailer) to track admin actions and notify employees on
create, update, delete, and restore events.

• Developed secure admin and employee login, allowing admins to manage employees and employees to view their
own profile details.
